# 🐻 Bear.AI

Bear.AI — многофункциональный помощник, созданный на HTML.

## 🚀 Возможности

- 💬 Чат
- 🧮 Калькулятор
- 📝 Решение задач
- 📚 Помощь с домашкой
- 🎮 Создание и запуск HTML-игр
- 💻 Работа с кодом
- 🕘 История
- ⭐ Избранное
- 🎨 Темы оформления
- 🎤 Голосовой ввод

## 📱 Запуск

Откройте `Index.html` в браузере.

## 🔥 Проект

Bear.AI создан как большой HTML-проект, который работает в одном файле.
